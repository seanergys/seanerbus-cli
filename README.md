# SeanerBUS Command-Line Utility

This sub-directory contains the SeanerBUS command-line utility, with which you can send messages or subscribe from the command-line:

```
./cli.py subscribe c3a554d4-ec63-44e6-a37f-d40540cc4b04
```

See `./cli.py --help` for more information.
