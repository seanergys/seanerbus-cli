# SeanerBUS Command-Line Utility

With this tool you can perform common dataplane tasks from the command line:

Such as subscribing to a metric:

```
./cli.py subscribe c3a554d4-ec63-44e6-a37f-d40540cc4b04
```

See `seanerbus --help` for more information.
